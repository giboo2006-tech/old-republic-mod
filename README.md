# Star Wars: Echoes of the Old Republic

A Fabric mod bringing the Star Wars Old Republic era to Minecraft.

- Minecraft 26.2, Fabric Loader 0.19.5, Fabric API 0.161.0+26.2
- Java 25
- Mod id: `oldrepublic`

## What's in Milestone 1

A first playable slice, from Force-sensitive wanderer to your first lightsaber:

- **The Awakening.** After 2 in-game days alive, or after a night's sleep, a whispered dream ends in an uncontrolled Force burst. You get the Wanderer's Journal, the Force Energy meter and Midi-chlorian Resonance.
- **Progression.** Force Attunement levels 1 to 100, skill points, Force Energy, Resonance milestones, per-ability mastery and anti-grind kill XP. Everything is server-authoritative and kept on death.
- **Meditation.** Crouch still with the journal to meditate; the first meditation teaches Force Push.
- **Force Push.** Hold to charge, release to push mobs, items and projectiles. From level 3, pick one branch: Repulse Wave, Focused Blast or Deflecting Pulse.
- **The Calling.** Holding the journal shows and sounds the pull towards the nearest crystal cave.
- **Crystal caves.** A generated structure with a Crystal Poacher camp at the mouth, glowing kyber clusters, unstable clusters that discharge if you linger, a hidden chamber and a sealed trial chamber.
- **Crystal Poacher.** A ranged mercenary with a blaster rifle, a visible and audible tell before every shot, bursts, retreats and cover. Drops hilt parts, with a guaranteed emitter by the 4th kill.
- **Trial of Reflection.** Kneel at the Meditation Stone to face your Shadow Echo. Win it and a kyber crystal attuned to you forms on the stone.
- **Lightsaber.** Build it at the Lightsaber Workbench from crystal, emitter, grip and pommel; pick a blade colour (cosmetic). Parts change damage, speed, reach, guard stamina and parry window. Guard to block melee and deflect blaster bolts; a well-timed guard parries.
- **Effects.** Particle, light and sound effects for every moment, with quality presets and separate screen-shake and flashing settings. All textures, sounds and structures are original placeholders generated by scripts.

## Build

```
./gradlew build
```

The mod jar lands in `build/libs/`. Every push also builds on GitHub Actions, and the jar is attached to the run as an artifact.

## Run in a dev client

```
./gradlew runClient
```

## Testing

```
./gradlew build
```

runs the server game tests (progression, Force Push, quest, saber and world rules, structure templates) on a dedicated server, which also proves the mod boots server-side.

```
./gradlew runClientGameTest
```

runs the client game test. It boots the game, joins a world and walks through the slice (Awakening, Force Push, Force screen, journal, workbench and saber, poacher and guard, crystal cave and trial, a dedicated-server push), saving screenshots to `build/run/clientGameTest/screenshots`. GitHub Actions runs both and uploads the screenshots.

## Operator commands

All under `/oldrepublic` and need operator permission (level 2). They act on the player running the command unless a player argument is given.

| Command | What it does |
|---|---|
| `/oldrepublic progress [player]` | Shows level, XP, Resonance, skill points, energy, quest stage, abilities, push branch and mastery. |
| `/oldrepublic awaken` | Triggers the Awakening now. |
| `/oldrepublic setlevel <1-100>` | Sets your level (XP to 0). |
| `/oldrepublic addxp <amount>` | Grants attunement XP. |
| `/oldrepublic grantskillpoints <1-100>` | Grants skill points. |
| `/oldrepublic energy fill` | Refills Force Energy. |
| `/oldrepublic quest set <0-6>` | Sets the quest stage: 0 Stirring, 1 Focus, 2 Practice, 3 Calling, 4 Trial, 5 Construction, 6 Complete. |
| `/oldrepublic quest reset` | Resets **all** your Force progression (level, Resonance, abilities, quest) to a fresh character. |
| `/oldrepublic journal` | Gives you the Wanderer's Journal if you do not have one. |
| `/oldrepublic push grant [player]` | Teaches Force Push. |
| `/oldrepublic push branch <none\|repulse_wave\|focused_blast\|deflecting_pulse>` | Sets the push branch directly (no level or skill point check). |
| `/oldrepublic push cooldown` | Clears the push cooldown. |
| `/oldrepublic push fire` | Casts a fully charged push (spends energy). |
| `/oldrepublic saber give [<color> <emitter> <grip> <pommel>]` | Gives a saber attuned to you (default: blue, guardian, wrapped, weighted). |
| `/oldrepublic saber crystal [<color>]` | Gives a kyber crystal attuned to you (default cyan). |
| `/oldrepublic saber parts` | Gives one of every hilt part. |
| `/oldrepublic saber stamina [refill]` | Shows (or refills) your guard stamina. |
| `/oldrepublic locatecave` | Finds the nearest crystal cave and prints its position and distance. |
| `/oldrepublic trial start` | Starts the Trial of Reflection at a Meditation Stone within 16 blocks (or where you stand), skipping the requirements. |
| `/oldrepublic trial stop` | Ends your running trial. |
| `/oldrepublic trial reset` | Ends your trial and clears your trial and crystal progress so it can be done again. |

Colours: `blue`, `green`, `yellow`, `violet`, `cyan`, `orange`, `red`, `silver`. Emitters: `guardian`, `duelist`. Grips: `wrapped`, `ridged`. Pommels: `weighted`, `balanced`.

Client-side comfort settings (any player, saved to `config/oldrepublic/client.json`):

| Command | What it does |
|---|---|
| `/oldrepublicfx` | Shows the current settings. |
| `/oldrepublicfx preset <reduced\|standard\|high\|cinematic>` | Effect quality preset. |
| `/oldrepublicfx shake <0-100>` | Screen shake strength in percent. |
| `/oldrepublicfx flashing <on\|off>` | Flashing effects. |
| `/oldrepublicfx hud <on\|off>` | Shows or hides the mod HUD. |
| `/oldrepublicfx volume <0-100>` | Mod sound volume in percent. |

## Controls

Default keys, all in the "Echoes of the Old Republic" category of the Controls screen:

| Key | Action |
|---|---|
| R | Use Force Power: hold to charge Force Push, release to fire. Releasing in under 0.25 s cancels with no cost. |
| K | Force Abilities screen (choose a push branch). |
| J | Open Journal. |
| G | Toggle Lightsaber (ignite or retract the saber in your hand). |

Other actions:

- **Sneak + use** with a lightsaber: ignite or retract it.
- **Use** (hold) with an ignited lightsaber: guard. The first moments of a guard are the parry window.
- **Sneak and stand still** on the ground with the journal in hand (once awakened): meditate.
- **Use** the journal item: open the journal.
- **Use** a Meditation Stone in the trial chamber: start the Trial of Reflection.
