# Quest and HUD assets

All textures are **placeholders**, original art generated by `tools/assets/gen_textures_quest.py` (PIL, deterministic;
run from the repository root). No Star Wars game or film assets are used or imitated. Sounds are the shared placeholder
sounds from `ModSounds` (see `docs/AUDIO_BRIEF.md`); this feature adds none.

| Path (under `src/main/resources/`) | What it is | Status | Brief for the final artist |

Page edges visible on the right. A faint embossed mark on the cover that belongs to no faction. Muted palette, readable at 16x16 in the hotbar. |

HUD elements other than the two icons (energy meter frame and fill, XP bar, focus ring, banners, notice plate) are drawn
with filled rectangles and gradients in code, so they stay crisp at every GUI scale. If a final UI artist wants a
textured frame for the energy meter, the frame is 88x9 at (5, 5) in GUI pixels.
