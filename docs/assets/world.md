# World assets: crystal caves and the Trial of Reflection

All textures are **placeholders**, original art generated by `tools/assets/gen_textures_world.py` (PIL, deterministic;
run from the repository root). The structure templates are generated by `tools/assets/gen_structures.py`
(deterministic: running it twice gives byte-identical NBT). No Star Wars game or film assets are used or imitated.
Sounds are the shared placeholder sounds from `ModSounds` (see `docs/AUDIO_BRIEF.md`); this feature adds none.

## Brief for the final structure builder

The generated pieces are functional placeholders. A builder replacing them in a structure block must keep:
the jigsaw blocks (names, targets, pools, orientations listed in `docs/design/world.md` section 3.3), the template
sizes or the cave tests in `WorldGameTests` (update the expected sizes there), the meditation stone at heart-local
`(22, 1, 38)` (`CaveLocator.HEART_STONE_LOCAL`), the resonant seal as the only way into the trial chamber (radius
about 7 around the stone, height 6), the crystal-veined wall as the only way into the hidden chamber, and the
unstable clusters placed so the 2.5-block danger radius covers the walkway.
