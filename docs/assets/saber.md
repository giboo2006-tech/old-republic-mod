# Saber assets: lightsaber, hilt parts, kyber crystal, workbench

All textures are **placeholders**: original art generated by `tools/assets/gen_textures_saber.py` (PIL, deterministic;
the script also writes every model, item definition, blockstate and particle JSON listed below). No Star Wars game or
film assets are used or imitated: hilts are generic cylinders with original detailing, not recognisable film props.
Sounds are the shared placeholder sounds from `ModSounds` (`SABER_*`, `WORKBENCH_SLOT`, `WORKBENCH_ASSEMBLE`; see
`docs/AUDIO_BRIEF.md`); this feature adds no sound files.

Paths are under `src/main/resources/`.
