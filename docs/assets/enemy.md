# Enemy assets: Crystal Poacher and blaster

All textures are **placeholders**: original art generated by `tools/assets/gen_textures_enemy.py` (PIL, deterministic;
run from the repository root). No Star Wars game or film assets are used or imitated. Sounds are the shared placeholder
sounds from `ModSounds` (`BLASTER_CHARGE`, `BLASTER_FIRE`, `BLASTER_BOLT_FLYBY`, `BLASTER_IMPACT`, `POACHER_HURT`,
`POACHER_DEATH`; see `docs/AUDIO_BRIEF.md`). This feature adds no sound files.

The blaster bolt has no texture: it is three nested additive boxes drawn in code (`BlasterBoltRenderer`), red haze,
orange glow and a near-white core. The muzzle glow during the tell is drawn the same way (`MuzzleGlowLayer`).
